## 实现要点（验收对照）

- **N1**：`build_background_package` 的 system/public 双模式真实截止过滤；版本选择按"截至时刻可见的最新版本"而非 `is_current`；提取须在截止前创建；claim 取截止前最新修订（public 模式还要求所引版本当时已公开）；未知时间一律排除不伪装；先过滤后 limit；包显式携带 generation/逐来源 version_id+extraction_id/digest；非法 as_of 400（`invalid_as_of`）。
- **N2**：登记只取当前版本**最新**提取且其为 ready；完整身份（模型/提示词/模板）判重；租约执行器（claim/lease/过期回收/attempts）；分析读**本文档自有块**（非全库检索）走既有预算化 `execute_analysis_run`（引用核验、运行持久化、N4 计数）；done→持久 run+result+发布事件；预算耗尽排队不外发；不可重试失败如实 failed；发布到生成区 `分析报告/`（机器溯源+引用核验+模型草稿+**引用原文块**+待复核横幅，append-only 人工优先）与派生 `分析索引.md`（只链盘上文件，待发布标记）。
- **N3**：`summary_outbox.event_key` 唯一→同事件恰一行/一版；无提供者时消费为**保留证据身份的可恢复阻塞版**（非空成果版）；提供者就绪后 `enqueue_blocked_entity_refreshes` 幂等恢复；文档 symbol→公司实体**首篇即映射**（impact 消费前入队 `document_added`）；双观点报告驱动同一实体并保留双方证据，无关实体不更新；每修订一页不可变文件 + 派生 `总结索引.md`，人工编辑不被覆盖。
- **worker**：`run_cycle` 增加 chat/ledger 接缝；生产传 None 时一切保持 blocked（回归证明 usage_events=0）；分析执行/分析发布/总结消费/总结发布全部纳入周期。
- **N4**：物理请求=每失败尝试的使用行 + 成功调用的业务行 + 在途预留，各自恰计一次；cap=2 允许一败一重试、第三次拒绝；并发在途占用槽位；重启后上限仍生效。
- **N5**：目录只链接盘上存在的笔记；未发布项标"待发布（下一轮自动发布）"并计入头部；中断恢复后链接全部可解析；无需调大批量或手工导出。
