## 已确认的耗时原因

原流程把审查包直接作为发布批次。`build_generation()`在投影变化后会遍历全部有效正文生成完整索引；因此29页的小批也要承担全库构建成本。同批隔离环境的索引构建实测约864.9秒，准备时一致性数据库副本38,736,158,720字节。

合并后仍保留一次隔离构建和一次生产构建。收益是减少发布批数、备份次数、全库索引构建次数及停服窗口次数，不是承诺索引单次耗时下降。增量索引、在线构建切换和历史索引回收另列后续优化，当前不扩展实现。

## 接续方式

1. 继续按最多30页生成、检查审查包；未确认区域保留原文。
2. 只有真实视觉验收、精确字符映射通过且审批绑定清单哈希的包可以入发布队列。
3. 把同一冻结范围中已经验收的包合并为一个不可覆盖的新发布目录。下一组118项材料可分四包审查，最终仅合并通过的子集；材料生成或模型一致不等于通过。
4. 合并器保持每份manifest和图像的原始字节，记录每个来源包、审批文件、清单和资产的哈希；重复页面、冲突、缺失或变更文件直接拒绝。异常项不能因合并被提升为confirmed。
5. 前批确认发布和恢复服务后，再开始一个新合并批次。仍只有一个发布写者；隔离检查、真实来源/current/head验证、一致性冻结备份、严格应用、一次索引、正文发布、接口和同步核验按既有流程执行。
6. 无已验收内容时保留队列等待验收，不启动空批；可确认部分不为无法确认项无限等待。

## 工具及门禁

- `scripts/ops_chart_release_bundle.py`：只读取已验收输入，创建新合并目录，不连接生产服务或修改数据库。
- `scripts/ops_chart_release_sequence.py`：使用固定哈希的旧接续器，按合并清单动态传入数量与独立容器名，保留旧镜像、checker、隔离/幂等/回退及发布门禁；提供只读计划和显式执行入口。
- 当前29页运行目录不覆盖、不重启、不作为待发布新输入。所有真实资料、审批清单、图片、配置和运行结果仅保存于忽略的runtime或服务器operation目录。
- 不重新调用GLM/OCR，不按模型置信度生成审批，不删除文件，不替换历史数据库。用户docs/37修改不属于本任务。

## 验收标准

| 项目 | 必须满足的结果 |
| --- | --- |
| 正常合并 | 两个不同已验收包的manifest/asset集合准确合并，逐文件字节与SHA不变 |
| 审批保真 | 审批状态、完整manifest hash集合、真实confirmed字段有效；proposal拒绝 |
| 冲突防护 | 重复页、不同版本/提取冲突、文件名冲突、篡改或漏资产均拒绝 |
| 路径保护 | 拒绝路径逃逸、符号链接和已有输出目录；验证失败不覆盖任何原输入 |
| 接续保护 | 前批未通过或仍有准确apply容器运行时不开始新发布；不盲目重试旧批 |
| 原发布兼容 | 输出通过固定checker及supervisor所需inventory验证，动态数量不放宽原门禁 |
| 成本约束 | 一个合并目录只启动一次隔离检查和一次生产发布；没有逐子包重建循环 |
| 线上闭环 | 原文/人工区/历史保持，接口和文件核验实际通过；Windows按实际hash匹配范围报告 |

## 操作入口

合并只接受已经审查通过的release目录，不能直接把`followup-reviews`材料包当作输入：

```text
python ops_chart_release_bundle.py --batch <approved-release-a> --batch <approved-release-b> --out <new-operation>/bundle
```

输出`bundle-result.json`及其SHA是下一次接续的固定输入；源审批和文件字节全部保留。新operation中使用`prepare-native-01/isolated-prepare-result.json`记录一致性准备结果，这是对旧固定接续器布局的兼容要求。将原固定checker复制到bundle根并核对SHA，再准备独立state/Vault隔离副本。不得从此前批次挪用隔离结果、启动记录或数据库副本冒充本合并批次通过。

`ops_chart_release_sequence.py --help`列出完整参数。先使用`--plan`核对合并hash、前批发布记录、准确apply容器退出0、服务恢复记录和旧接续器hash；计划不启动写者。随后同参数以`--execute`启动一次。新operation必须与前批目录分离，显式指定新的isolated容器名。进程断开后服务器仍执行旧的经过固定校验的隔离→冻结→生产发布链；恢复先读检查点，不重复execute。
