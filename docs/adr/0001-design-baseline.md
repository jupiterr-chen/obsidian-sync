# ADR 0001：设计基线与分阶段上线

状态：设计采纳，2026-10-01；实现待验收。

决定：保留library为来源接入入口；新工程建立版本化正文及证据服务；Obsidian保留人工研究。使用模块化单体、SQLite起步、不可变文件产物和影子发布。将生成式LLM放在P4以后，关键词全文可先独立交付。

原因：当前523份，最主要风险是提取质量、证据定位、版本和人工笔记保护。增加分布式组件或全量模型摘要不能解决这些基础问题。

后果：单节点索引发布；数据库活文件不同步。性能和并发实测超出目标时再迁移。服务端源码不可达、真实页数未知，因此生产容量和模型预算在P1校准。所有旧证据版本需要可定位的保留机制。
