# 验收基准与门禁

以下是拟定目标，未运行的性能或质量测试不表示已经达标。P1 样本后允许有理由地修订阈值并记录 ADR，但不能在看到盲测失败后无记录地降低门槛。

|编号|测试与场景|通过标准|证据|
|---|---|---|---|
|A00|设计基线|文档链接全部可解析、JSON及schema有效、计划覆盖设计、无敏感数据提交|P0验证报告|
|A01|来源清单及身份|清单总数/分格式与服务器一致，差异逐条列出，sha256/版本/原文路由验证|对账报告|
|A02|幂等|同样输入连续运行3次：document、version、extraction、block及最终生成文件数量无新增重复|数据库计数及文件哈希|
|A03|版本与失败恢复|源更改、解析配置更改均生成独立版本；每阶段模拟中断后恢复；旧active保持可读|故障注入报告|
|A04|样本与标注|30份分层样本、20调优/10盲测、各类风险至少覆盖；关键数值人工标注|私有样本manifest|
|A05|Token测量|记录目标tokenizer及版本、文本hash、逐文档token、覆盖率和未提取名单；估算区间不冒充精确值|测量报告|
|A06|正文可用性|每个源明确ready/review/failed；盲测正常文字页人工标注段落覆盖≥98%；多栏阅读顺序正确段落≥95%|标注对照|
|A07|证据定位|盲测至少100个引用，源版本和文档正确率100%，页/段落定位≥99%；旧引用在重提取后仍可打开|链接巡检|
|A08|OCR质量路由|所有标注扫描页被路由OCR；所有标注严重乱码/遗漏页被标记；OCR结果分质量统计，不预承诺全体文字准确率|页级报告|
|A09|财务表格|至少100个重要数值（含负数、单位、期间、币种、合并表头）；进入可计算集合的值与口径100%正确，未知/错误被排除|数值核对表|
|A10|搜索效果|至少50个真实研究查询、人工相关集；keyword Recall@10≥0.85；hybrid目标≥0.90且精确代码/数字不退化|查询基准报告|
|A11|短词与时间|毛利等两字词、代码、中英缩写、数字可检索；as_of不返回不满足该模式可用时间的文档|契约测试|
|A12|API与分页|权限先过滤；跨generation分页一致/明确过期；错误结构、limits和契约满足|集成测试|
|A13|访问控制|无认证无法读取；跨集合/个人笔记/撤权历史访问被拒绝；日志无凭据|安全回归|
|A14|全量对账|当前523基线及执行时新增全部有状态；无静默漏文档；发布前后索引数可解释|回填报告|
|A15|人工区与同步|处理前后人工区字节hash一致；生成区手改及sync-conflict不被覆盖；无个人笔记进入Git|前后manifest|
|A16|embedding成本|provider/model/tokenizer/维度/配置记录；token覆盖及账单类别可解释；预算超限停止新任务|成本报告|
|A17|分析引用|至少30问，全部引用存在且权限正确；人工核验可核实事实有有效支持≥95%，无依据关键数值进入自动输出为0|问答审查|
|A18|LLM故障|超时/429/预算超限/重复投递不会重复发布或无限重试；未知输出显式标记；拒绝格式外内容|故障测试|
|A19|记忆与决策|确认/拒绝/质疑/替代均留历史；旧决策证据清单不随新版本变化；人工编辑保留|状态机测试|
|A20|更新影响|至少20组有标注的新旧报告，受影响claim召回≥90%，建议更新不自动覆盖接受版本|影响评测|
|A21|稳定性与延迟|声明服务器配置、并发5；关键词P95≤1秒、混合P95≤3秒（排除LLM生成）；正常新文档完成后5分钟内发布；连续7天无丢任务|负载与运行报告|
|A22|恢复|测试目录恢复后清单hash/历史引用一致，达到RPO≤24h、RTO≤4h；回滚不改人工区|恢复演练|

## 不能省略的反例

同名不同文档、同哈希不同来源、同源版本哈希异常、PDF混合扫描、空白封面、多栏串行、HTML隐藏XBRL重复、日期未知、文件暂时失联、访问撤权、两字中文词、金额单位错位、原文修改、解析升级、模型伪造引用、用户手改生成稿。

## 报告模板

使用 `tests/acceptance-report-template.md`。生产或硬件尚未具备的测试填 NOT_RUN；不使用 PASS 代替计划。每阶段发布包括已通过、未通过、适用样本和风险限制。
