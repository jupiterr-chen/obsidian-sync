**G1：可进入影子验收。** T01–T07 已有有效 RED/GREEN，旧库可升级，配置/算法更新确实生成新身份，资金/版本/证据/幂等边界通过，完整旧回归无退化。此时可在隔离数据目录运行小批处理，不代表可以切换生产。

## N5 的最低真实证据

验收标准沿用 [docs/08](08-acceptance.md)，不在盲测后降低阈值。

- A01/A02/A03/A14：按实际运行时清单对账；新旧 recipe 均有状态；连续三次重跑无重复块/候选；中断恢复后旧 active 仍可读。
- A04/A06/A08/A09：30 份分层样本、10 份独立盲测；正常段落覆盖≥98%、阅读顺序≥95%；扫描/严重乱码/遗漏页全部识别；至少 100 个重要财务数值的单位/期间/币种正确，未知不得进入计算集合。人工标注不足时如实 NOT_RUN，LLM 不能替代金标准。
- A07/A11/A12/A13：至少 100 个真实引用，版本/文档100%正确、位置≥99%，重提取后旧引用可读；时间边界/分页/认证/集合访问覆盖。
- A10：50 个真实研究查询及相关集，keyword Recall@10≥0.85。真实 embedding 未启用时，hybrid 质量保持 NOT_RUN；mock 只能证明协议/算法路径。
- A15/A19/A22：人工区前后 hash 不变；在隔离生成目录验证写回及冻结证据；脱离生产目录可恢复数据库+blob并打开历史引用，记录 RPO/RTO 实测。
- A05/A16：对已提取文本做本地 tokenizer 测量，记录 tokenizer/版本/hash/覆盖率和未提取清单。OCR 页数/模型请求与文本 token 分别计量，不能用全文 token 等同视觉成本。不知道目标 tokenizer 时先给字符/页数清单和估算标记，不编造精确 token。
- A17/A18/A20/A21：真实模型质量、20 组影响标注、性能与7天运行单列，未执行不标 PASS。上线后的7天观测与上线前隔离稳定性测试分别记录。
